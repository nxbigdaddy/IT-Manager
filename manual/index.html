建议屏幕宽度1366像素以上。打印采用A4横向；目录导航与分页按钮在打印时隐藏。每个主题为独立HTML文件，适合后续CHM整理；图像可点击打开原图。

截图由当前Qt程序在隔离演示数据下生成，不含正式业务信息，不代表人工视觉验收通过。真实AI/消息平台未联调。编辑弹窗截图可能不含操作系统绘制的原生标题栏。

IT推进管理工具 · 源码交付版 · 面向单个可信IT管理员。浏览器直接打开本页即可阅读，无服务器、CDN或网络资源依赖。

先明确边界：默认本地SQLite；人员是管理对象，没有员工登录；SMTP仅发送；其他数据库仅预留适配口；真实机器人、邮箱及AI平台尚未完成外部联调。关闭服务后周期任务不执行。

建议阅读路径

  1. 首次使用：安装启动 → 架构与连接 → 规划任务 → 台账与考核。
  2. 对外发送：汇报审核 → 通知与邮件 → 凭据与安全 → 周期调度。
  3. AI与维护：AI与提示词 → 导入导出 → 备份恢复 → FAQ与限制。

本手册以实现为准，不把设计规划描述成已经交付的功能。章节可独立阅读，统一使用相对链接与本地样式。导航包含全部主题。
