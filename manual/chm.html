交付包含 itmanager.hhp（工程）、itmanager.hhc（目录）、itmanager.hhk（关键词索引），默认主题index.html，所有主题位于同目录并使用ASCII文件名。此次未编译、不提供CHM文件，也不要求安装HTML Help Workshop才能阅读HTML。

维护与生成

HTML与CSS均UTF-8，本地资源，无JS、CDN及远程图片。运行 python manual/build_manual.py 可从主题源码重新生成所有页面和工程源；修改时应修改生成器后重建，避免下次重建覆盖直接编辑。

旧版HHC中文兼容

HTML Help Workshop为旧版ANSI工具；仅设置Language=0x804不能保证所有环境正确解析UTF-8目录。源文件统一保留UTF-8，不要把主手册整体改成ANSI。

  1. 工程源目录及主题使用ASCII文件名；目录/索引的Name属性输出中文字符的数字实体，降低ANSI目录解析乱码风险。
  2. 若目标编译器仍显示实体或乱码，将工程复制到独立ASCII路径的构建暂存目录；仅在该副本把HHC/HHK中文名称解码为真实中文并编码为GB18030（常用简体中文也可用CP936），同时调整这两个文件的charset声明。
  3. 在简体中文系统区域设置下核验目录、索引、搜索和主题内容；UTF-8主题页本身继续保留明确meta charset，不修改原始源码。
  4. 如仍不兼容，可在构建副本采用ASCII目录名＋主题内中文标题作为保守退路；不要声称CHM中文已通过编译验证。

HHP配置简体中文Language标识和全局主题列表；主题采用简单HTML/CSS以兼容旧渲染器，但最终CHM渲染与全文检索仍需实际编译后验收。Windows下载文件可能被安全策略阻止，只有确认来源可信后才按组织政策处理；不要全局降低CHM或浏览器安全设置。
