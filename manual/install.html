准备条件

Windows、Python 3.11或更新版本、可写的源码目录。首次安装需能获取依赖，受限网络由管理员预备依赖包；不提供EXE、安装器或已编译CHM。中文及空格路径由BAT按自身所在目录处理。不要将数据放在多人共享网盘。

  1. 解压完整源码到固定目录，运行 setup_env.bat：创建/复用 .venv，安装依赖并检查PySide6等组件。
  2. 运行 start_local.bat：检查默认回环服务；未运行时另开服务控制台，健康检查后打开桌面。
  3. 顶部应显示已连接及调度器状态；先使用虚构人员和测试任务。
  4. 选择“帮助”打开本手册。不要在完成测试前启用自动发送。
脚本作用
setup_env.bat环境安装与依赖检查，失败保留提示。
start_local.bat本机服务＋桌面；复用健康且令牌匹配的服务。
start_server.bat仅服务，开启调度；默认127.0.0.1:18765。
start_desktop.bat仅桌面；服务必须已启动，支持--url及--token-file。
run_tests.bat无界面自动测试；不等于真实外部联调通过。

数据与停止

本机启动器使用源码下 data，首次生成随机 admin.token，业务库为 itmanager.sqlite3。令牌不是员工密码，不要发进群。关闭桌面不停止服务；要停止周期执行，在服务控制台按Ctrl+C并确认进程退出。重启电脑后应重新启动或配置受控托管。

安装失败先检查Python版本、网络、磁盘、依赖下载信息；不要反复删除数据目录。升级前先做一致性备份。
