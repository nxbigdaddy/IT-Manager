# 05 集成、AI与安全设计

## 通知
群机器人仅官方HTTPS域名和合法hook路径；拒绝重定向，验证TLS，不接受任意内网URL。飞书/钉钉按配置签名；检查HTTP和平台业务结果。机器人凭据与正文不写日志。

SMTP支持SSL及STARTTLS且验证证书，不降级明文；配置发件地址、明确收件人列表，拒绝头部注入；附件限定服务生成目录、数量和大小。发送前展示目标，不自动从员工数据推断群发范围。

发送状态：pending→sending→sent / failed / uncertain。每次发送有幂等请求ID；周期唯一键为计划ID＋执行槽位。确定未发出时可有限退避重试；已发出但响应超时/断线属于uncertain，仅在用户核对后明确重发，不能承诺跨第三方“恰好一次”。服务重启恢复遗留任务，不静默重发。

## 调度
每日/每周/每月，显式IANA时区；月31日在短月截断为月末；DST缺失时间顺延、重复时间仅执行一次。启用前显示下次执行和范围。恢复服务默认最多补一个错过槽位并记录late，随后计算未来槽位，不补发所有历史。明确“生成草稿”和“授权自动发送”两种模式；默认草稿。

## AI
三平台OpenAI兼容聊天接口，地址限定对应官方域名，支持地域配置；模型名称显式可编辑，不保证建议模型对所有账号可用。参数校验、超时、响应大小限制、错误脱敏。连接测试使用最小测试文本并提示可能收费。

提示词变量只允许{{标识符}}替换，不执行Python或表达式。业务资料视为不可信数据，不作为系统指令。版本历史、调用模型/提示词版本/用量/状态可查询；不保存密钥，默认不额外保存原始敏感请求正文。

任务生成仅建议，用户选择确认后创建；考核仅证据摘要，不自动定级。数据发送前选定范围、预览；人员/考核/权限字段需要额外确认。AI失败不能影响原业务记录。

## 密钥及认证
首版单可信管理员Bearer令牌，至少24字符高熵随机值；远程HTTPS；不是多人权限系统。初始服务令牌由本机安全初始化，不进入Git。环境变量引用适配已有原型；GUI密钥配置需增设服务端受控凭据库：Windows使用DPAPI或可用系统凭据存储，Linux使用部署者提供的外部密钥/受限环境文件，不自制加密。未具备安全存储时GUI只能填写环境变量名，清楚提示功能边界，不能落明文数据库。

令牌、API Key、Webhook、SMTP密码、私钥不得进入版本库、导出、日志、报告或错误消息。限制请求大小、超时、文件路径和附件；备份继承同级权限。数据库含考核信息，即使无密码也属敏感资料。

## 威胁及控制
| 威胁 | 控制 |
|---|---|
| 任意URL SSRF/凭据转发 | 官方域名限制、HTTPS、禁止重定向 |
| 明文泄露 | 密钥引用/系统保护、脱敏、Git忽略与检查 |
| 重复发送 | 幂等键、持久发送状态、不确定结果人工核对 |
| 提示词注入 | 数据与指令区分、无工具执行、人工审核 |
| 考核失公允 | 证据和复核、禁止AI自动定级 |
| 误覆盖/误上线 | 乐观锁、历史、审批版本绑定、备份恢复 |
