# 01 需求与范围

## 产品目标
为IT负责人提供从年度规划到日常行动、证据记录、管理复盘和向上汇报的闭环工具。沿用已交付管理方法，不以堆砌台账替代工作推进。

## 已确认边界
- Windows原生桌面，**PySide6（Qt for Python）**；不采用Tkinter或Web GUI。
- 桌面通过API使用统一Python服务端；服务端常开执行周期任务。
- 企微、飞书、钉钉群机器人及SMTP发送；不收取邮件。
- DeepSeek、Kimi、Qwen API及提示词管理；AI结果必须可审阅。
- 先建立完整设计文档、更新日志、本地Git，再推进GUI实现。

## 需求清单
| 编号 | 需求 | 首版验收结果 |
|---|---|---|
| R01 | 长期规划、项目、父子任务、责任、期限、优先级 | 能从规划关联到任务并追踪交付和逾期 |
| R02 | 日常记录和完整IT台账 | 支持查询、新建、修改、筛选、证据链接及审计 |
| R03 | 人员、职责和考核 | 目标、周期、证据、自评、主管评价、反馈、复核；不自动决定等级 |
| R04 | 工作看板 | 未结任务、逾期、高风险、待决策、合同到期；可下钻 |
| R05 | 汇报 | 按周期、负责人、模块生成可编辑草稿，批准后导出或发送 |
| R06 | 通知与邮件 | 三平台群机器人、SMTP TLS、附件、发送结果及幂等处理 |
| R07 | 常驻调度 | 日/周/月、时区、启停、预览下次时间、漏跑记录与受控补发 |
| R08 | AI配置 | 三平台、官方地域地址、模型参数、密钥安全配置、连接测试 |
| R09 | 提示词 | 分类、变量、版本、启停、复制、试运行及调用记录 |
| R10 | AI业务辅助 | 选定记录生成汇报、任务建议、纪要、风险分析、邮件和考核证据摘要 |
| R11 | 数据维护 | Excel/JSON导入导出、预览校验、备份恢复及版本迁移 |
| R12 | 安全和可部署性 | 认证、远程HTTPS、凭据隔离、日志脱敏、独立服务和桌面启动 |
| R13 | 易用性 | PySide6中文GUI，异步操作、错误提示、未保存提醒、可取消长操作 |

## 首版使用人及权限
暂定一个可信IT管理员使用客户端管理人员，人员为管理对象而非默认登录用户。这是实现假设，不是已确认的多人权限需求。不能将共享管理员令牌的首版直接开放员工自助使用。多人账号、部门隔离、员工自评门户需另立阶段，确认前不宣称支持。

## 首版之外
企业通讯录同步、平台个人消息/回调、收邮件转任务、SSO、复杂流程引擎、移动端、薪酬计算、AI自动决策/自动执行工具、分布式高可用。

## 待用户确认（不阻塞文档与本机开发）
服务器系统及部署权限、网络与HTTPS条件；预计人员/记录量；是否后续多人登录；邮箱服务商及授权方式；企业机器人安全策略；AI账号地域；公司数据外发政策及保存期限；安装包及代码签名要求。
