# v0.4 IT管理辅助闭环扩展

## 原则
本轮不扩充大量独立台账，重点连接现有记录：任务推进有日志、检查异常有风险与整改、AI建议有确认后的行动、项目人员有相关工作视图。单管理员、SQLite与原启动入口兼容；不自动联系员工或外发消息。

## 功能
1. 任务快捷推进：记录进展、阻塞、提交验收、完成、延期。任务修改与工作日志同一事务；延期必须理由与批准人，保留原期限。已终结任务不能用快捷入口重新推进。
2. 检查中心：备份运行、入离职权限、合同续费、项目周检模板；所有结果默认待检查。异常必须说明，提交后生成不可变检查记录、风险及整改任务，关联可追溯。
3. 关联视图：项目、人员、任务等详情可以查看有关联ID/负责人姓名的记录；姓名匹配只是辅助检索，不是权限或可靠组织身份。
4. AI建议转任务：基于实际AI调用或已存在业务记录，人审选择/编辑任务名称、负责人、截止、下一步和验收条件后建立任务。不直接执行模型JSON，不把建议变成已批准事实。

## 接口与可靠性
POST /tasks/{id}/action，POST /actions/create，POST /checklists/complete。均需要16—100字符request_id幂等键；重复请求返回原结果而不重复创建。任务推进带版本CAS；任务更新与日志、检查记录与风险整改、批量任务要么一起提交要么一起回滚。GET /checklists/runs展示完成记录。所有网络错误保留输入和请求ID，修改数据后使用新请求ID。

## 验收
任务→进度日志→阻塞→提交验收→完成；延期日期历史；检查异常→风险＋任务→完成；AI生成→字段预览→选建议转任务→记录来源；重复提交不重复生成。Qt界面操作与真实SQLite服务闭环均测试，外部AI和消息仍mock。
