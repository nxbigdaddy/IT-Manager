# v0.8 第三波：体验与AI

## 交付内容
1. **快捷键**：F5/Ctrl+R 刷新，Ctrl+N 新建，Ctrl+E 编辑，Ctrl+H 历史，Ctrl+F 搜索，Ctrl+B 批量，Ctrl+1/2/3/4 跳转工作台/提醒中心/数据体检/统计看板，Ctrl+T 主题，Ctrl+=/Ctrl+-/Ctrl+0 字号，Ctrl+, 连接设置，Ctrl+D 工作台卡片。无可用操作时给出说明而不是静默失败。
2. **深色模式与字号**：浅色样式表作为唯一结构来源，深色只替换配色令牌，避免两套主题布局漂移；字号 0.85—1.45 倍，作用于全局。偏好用 QSettings 存在本机。
3. **工作台卡片可配置**：今日任务、逾期任务、高风险、待决策、30天内到期合同、待处理提醒、体检发现、最高负载负责人；默认含提醒条，全部取消时给出提示而不是空白页。
4. **图表下钻与导出**：柱条可点击（悬停有提示），模块图点击进入对应模块，风险图进入风险台账；“导出图表与数据…”输出 PNG 与 charts-data.json，取消不写文件。
5. **AI 周报自动汇总**：按时间范围与负责人统计记录、生成提示词、单次模型调用、落为**待审核草稿**；含人员/考核/权限时要求二次授权。
6. **会议纪要转任务**：模型只做抽取；候选任务进入人工确认窗口，默认全部不勾选，负责人只能来自服务端真实人员记录，日期/优先级非法值被清空并列出原因；确认后经既有批量接口建任务，来源为对应 AI 调用编号。

## 修复的真实缺陷
- **汇报与草稿页点击即崩**：`button()` 只接受 3 个参数，而新增的 AI 按钮传了第 4 个（`primary=True`），一旦打开该页就抛 TypeError。该问题由全页面截图/冒烟流程发现，随后的 `test_page_smoke.py` 会遍历全部导航项并断言无异常——这类“某个页面从没被打开过”的缺陷现在有回归覆盖。
- **全量测试偶发失败**：`test_async_callback_is_gui_thread` 在完整套件中偶发超时。实测发现整套测试累计创建上百个窗口后，Qt 事件循环调度一个简单任务需要约 2 秒（单窗口进程只需毫秒级），属测试进程内的窗口泄漏，不是产品缺陷。断言改为保留线程亲和语义、给足超时，并在注释里写明原因，没有删除断言。
