# 03 功能流程与界面设计

## 导航与页面
| 导航 | 页面及核心操作 |
|---|---|
| 工作台 | 今日/逾期任务、高风险、待决策、到期合同、最近草稿、调度健康；点击下钻 |
| 规划与执行 | 长期规划、项目、任务；关联选择器、父子关系、筛选、详情、验收 |
| 人员与考核 | 人员职责、周期目标、成果证据、自评/主管评价/反馈、复核 |
| 日常运营 | 日志、事件、变更、信息收集、需求、决策 |
| 基础治理 | 系统、资产、权限、风险、合同、预算、恢复、指标 |
| 汇报中心 | 范围选择、生成草稿、编辑、审核、导出、渠道选择、发送记录 |
| AI工作室 | 模型配置、提示词库、试运行、所选数据预览、结果与调用记录 |
| 自动化 | 通知渠道、邮件配置、周期计划、下次执行、执行记录、人工补发 |
| 系统 | 服务连接、备份、导入导出、审计、版本与帮助 |

## 主窗口布局（文字线框）
```text
[应用名称] [服务连接状态] [数据刷新] [帮助]
[侧边导航] | [模块标题] [新建] [导入] [导出]
           | [关键词] [负责人] [状态] [日期范围] [清空]
           | 表格：ID / 名称 / 责任人 / 截止 / 状态 / 更新时间
           | [上一页] [页码/记录数] [下一页]
           | 当前选中记录摘要 / 关联对象 / 最近行动
```

详情编辑采用可滚动分组表单，必填字段标识、日期控件、数值校验、关联对象选择器，不要求用户手抄所有ID。长期文本支持多行。保存失败保留输入；未保存退出需确认。

## 任务闭环
草稿/未开始→进行中→待验收→已完成；另有阻塞/取消。完成需完成证据及验收人。阻塞需原因和下一步。父任务不得关联自身或形成环；项目/人员引用验证存在；子任务不自动全部完成。延期记录原日期、新日期、原因及批准，不改日期掩盖历史。

## 项目与规划
规划→项目→任务提供关联视图；里程碑与范围、预算、验收标准、收益复盘分开记录。完成率采用已定义里程碑或任务口径，不把任务数量当作业务收益。项目完成不终止收益复盘。

## 考核流程
设定周期/目标/指标及权重→确认目标→汇总证据→自评→主管评价→员工反馈→复核定稿。首版由管理员代录并注明来源，不宣称员工已在线签字。任务逾期需区分范围变化、资源等待等原因；AI仅整理证据，禁止自动扣分、自动排名或决定绩效等级。定稿后修订须留历史和理由。

## 汇报与发送
显示周期、负责人、模块、统计口径；生成后显示来源ID及数据截至时点。草稿内容可编辑，编辑后原审批失效；人工批准版本与发送版本绑定。收件渠道和邮件收件人必须发送前确认。自动汇报要求单独开启，展示周期、范围和目标渠道，允许随时停用。

## AI及提示词页面
模型配置为结构化表单而非强制编辑JSON：平台、地域/地址、模型、密钥状态、温度、输出上限、超时、测试。提示词显示分类、变量、版本和启用状态；历史版本可复制为新版本。发送前显示选中记录及字段，敏感对象二次确认。生成进度可取消等待；取消不保证上游已停止计费，界面明确说明。

## 错误和可访问性
网络超时、认证失效、版本冲突、校验失败、平台限流分别提示；不得把密钥或原始服务响应显示给用户。支持键盘操作、合理Tab顺序、缩放、高DPI、中文长文本与横向表格滚动；不能仅用颜色表达风险。
