# 全面审核与图文手册交付

## 范围与方法
对当前PySide6主界面、19业务模块、AI辅助、提示词与模型、通知发送、日常检查、专项体系、事务版本与幂等、备份恢复和使用说明进行源码核对、隔离复现与回归。没有访问正式业务数据，没有真实外部模型/消息调用。

## 已修复问题
1. 专项保存仅禁Save，仍能继续编辑，成功关闭会丢补充输入：改为冻结全表单，失败恢复且保留输入。
2. 页面刷新generation改变导致专项编辑器静默失效：请求生命周期绑定dialog/client，旧页面销毁不丢保存结果。
3. 检查提交后切页再返回出现按钮长期锁定：使用client+attempt身份更新新页面。
4. AI普通填表/通用草稿资料按ID重取可能发送未预览修改：客户端快照hash绑定选定记录，服务器拒绝发生变化或缺少校验的非空资料。
5. 提示词失败请求仍部分改变默认/历史：原子保存版本历史和默认切换，故障全回滚。
6. 专项表单跨Store并发CAS失效：事务内重新读取版本，竞争仅一方成功。
7. 模板编辑增加版本CAS，GUI携version；旧API缺省version兼容后写行为需谨慎。
8. 无效AI记录ID/变量、period_days类型导致500：增加输入校验。
