## 维护规则

- 需求变更先更新对应设计及验收，再修改实现；每次交付同步根目录更新日志。
- 每个需求保留编号；测试用例和里程碑引用编号，避免“界面有按钮”冒充功能完成。
- 不在文档、源码、截图、提交记录中放真实凭据或员工考核内容。
- 示例和现状严格区分；真实平台联调需用户授权和测试收件人。
- 代码原型与设计不一致时记录差异并修正，不能默认为设计已经实现。
