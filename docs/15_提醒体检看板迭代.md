# v0.5 提醒、体检、检查模板与统计看板

## 目标
从“记录台账”推进到“每天提示该做什么、资料缺什么、整体趋势如何”，四块能力都基于现有SQLite记录，不新增外部依赖、不改变单管理员边界。

## 交付内容
1. 提醒中心（`reminders.py` + `insights_ui.reminders_page`）：8条内置规则覆盖合同到期、资产维保、权限复核、恢复演练、考核周期、风险复核、任务逾期、长期未更新；规则可新建/编辑/复制/启停/删除/JSON导入导出，按版本CAS保存；工作台显示待处理提醒数量并可跳转。
2. 可配置检查模板（`checklist_templates.py` + 改造后的`checklists_ui`）：4套内置模板转为可编辑配置，支持复制、停用、导入导出与版本校验；未取到配置时回退内置模板，离线可用。
3. 台账数据体检（`health.py` + `insights_ui.health_page`）：10类检查（缺负责人、缺关键日期、缺证据、重复编号、超期未处理、失效引用、复核超期、长期未更新、系统缺恢复目标、考核缺口径），只读扫描，勾选后可生成整改任务，导出CSV/Markdown。
4. 统计看板（`charts.py` + `charts_ui.py`）：QPainter自绘，模块记录数、任务完成趋势（按截止日期分周，另计无日期任务）、风险等级分布、任务状态分布、预算汇总；工作台嵌入三张关键图表。

## 接口与安全
- `GET/POST /reminders`、`POST /reminders/delete`、`GET/POST /checklist-templates`、`POST /checklist-templates/delete`、`GET /checklist-templates/{id}/export`；服务端剥离存储信封字段（id/oldhistory/created/updated/version）后再做严格校验，版本由服务端管理。
- 删除都带版本校验；已被历史检查记录引用的模板拒绝删除并提示改为停用；内置提醒规则与检查模板只在首次初始化时写入（`seeds` 标记），用户删除后重启不会自动恢复。
- 新对象类型纳入`save_versioned_object`白名单，CAS与历史同一事务；删除走`delete_object`并写审计。
- 校验错误文案全部来自`SAFE_*`常量集合，经`errors.py`白名单显示，不回显用户输入。
- 提醒与体检在客户端本地计算，不发网络请求；整改任务复用`/actions/create`，沿用幂等请求ID。
- 工作台提醒条在尚未加载服务端规则时按内置默认规则估算，并在文案中明确标注，避免把估算值当作已配置口径。

## 验证
- 新增测试：`test_reminders.py`、`test_health.py`、`test_charts.py`、`test_charts_ui.py`、`test_checklist_templates.py`、`test_insights_ui.py`、`test_reminder_routes.py`。
- 服务与路由层：提醒规则与模板种子幂等、版本CAS冲突、导出不含内部字段、非法规则/模板返回400且带安全文案。
- 集成与闭环（父代理独立编写，全部用真实FastAPI+SQLite+Qt控件）：
  - `test_insights_integration.py`：真实MainWindow打开提醒中心/数据体检/统计看板，行数与`compute_items`/`scan`一致，工作台提醒条数量与本地计算一致；所有模态入口被替换为抛错桩，避免测试因真实弹窗挂起。
  - `test_checklist_template_end_to_end.py`：服务端保存的自定义检查模板出现在界面模板下拉；服务端提醒规则（放宽到10天）驱动工作台提醒数量；在界面提交一次含异常项的检查后，服务端真实生成1条风险与1条整改任务，检查记录保留异常说明，页面显示任务ID并锁定提交。
- 边界：提醒不是日程或消息推送；体检不代表合规结论；金额合计不换算币种；图表不下钻、不导出图片；台账质量仍需人工复核。
